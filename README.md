# PestoRiteshResturant

A clean, modern, and fully responsive **Restaurant Website** built using **HTML, CSS, and JavaScript**. This project is designed to showcase a restaurant brand, highlight menu items, and provide customers with an elegant browsing experience.

---

## ⭐ Project Overview

**PestoRiteshResturant** is a front-end restaurant website focused on simplicity, fast performance, and visual appeal. The theme uses a fresh "pesto green" color palette to create a premium dining feel.

This project is ideal for:

* Restaurant owners showcasing their menu online
* Students practicing front-end development
* Developers building a portfolio-ready UI project

---

## 🔥 Features

* Fully responsive website (mobile + desktop)
* Interactive navigation menu
* Beautiful hero section with restaurant branding
* Menu sections (Starters, Main Course, Desserts, Drinks)
* Smooth scroll animations
* Contact / Reservation section
* Clean and organized code structure

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ritesh-singh2004/PestoRiteshResturant.git
```

### 2. Open the project

Simply open `index.html` in your browser.

Or run a local server:

```bash
npx live-server
```
